# SkyProProject-2

Учебный проект на Python для работы с категориями и товарами.

Приложение загружает данные о категориях и товарах из JSON-файла, преобразует их в объекты Python и предоставляет возможность работать с полученными данными.

## Возможности

* загрузка данных из JSON-файла;
* создание объектов категорий `Category`;
* хранение информации о товарах внутри категорий;
* обработка ошибок при чтении JSON-файла;
* обработка отсутствующего файла;
* обработка отсутствующих обязательных полей;
* автоматическое тестирование функций с помощью `pytest`.

## Формат данных

Исходные данные находятся в файле `data/products.json`.

Пример структуры:

```json
[
  {
    "name": "Смартфоны",
    "description": "Смартфоны, как средство не только коммуникации, но и получение дополнительных функций для удобства жизни",
    "products": [
      {
        "name": "Samsung Galaxy C23 Ultra",
        "description": "256GB, Серый цвет, 200MP камера",
        "price": 180000.0,
        "quantity": 5
      },
      {
        "name": "Iphone 15",
        "description": "512GB, Gray space",
        "price": 210000.0,
        "quantity": 8
      }
    ]
  }
]
```

Каждая категория содержит:

* `name` — название категории;
* `description` — описание категории;
* `products` — список товаров.

Каждый товар содержит:

* `name` — название товара;
* `description` — описание товара;
* `price` — цена;
* `quantity` — количество товара.

## Загрузка данных

Для загрузки данных используется функция `load_data_from_json()`:

```python
from utils import load_data_from_json

categories = load_data_from_json()
```

По умолчанию функция читает файл:

```text
./data/products.json
```

При необходимости можно передать собственный путь:

```python
categories = load_data_from_json("data/products.json")
```

Функция возвращает список объектов `Category`.

## Обработка ошибок

Функция обрабатывает следующие ситуации:

### Файл не найден

Если указанный JSON-файл отсутствует, функция выводит сообщение об ошибке и возвращает пустой список:

```python
[]
```

### Некорректный JSON

Если файл содержит некорректный JSON, ошибка `JSONDecodeError` обрабатывается, после чего функция возвращает пустой список.

### Отсутствует обязательное поле

Если в данных категории отсутствует одно из обязательных полей:

* `name`;
* `description`;
* `products`;

возникает `KeyError`, который также обрабатывается функцией.

## Тестирование

Для тестирования используется библиотека `pytest`.

Запуск всех тестов:

```bash
pytest
```

Запуск тестов конкретного файла:

```bash
pytest tests/test_utils.py
```

Тесты проверяют:

* успешную загрузку данных;
* создание объектов `Category`;
* загрузку нескольких категорий;
* работу с пустым JSON-файлом;
* поведение при отсутствии файла.

Пример результата:

```text
4 passed
```

## Установка

Клонировать репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
```

Перейти в директорию проекта:

```bash
cd SkyproProject-2
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать виртуальное окружение в Windows:

```bash
.venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```
