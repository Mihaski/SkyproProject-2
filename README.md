# SkyProProject-2

Учебный проект на Python для работы с товарами, категориями и заказами интернет-магазина.

Проект реализует объектно-ориентированную модель товаров и категорий, загрузку данных из JSON-файла, наследование классов товаров, абстрактные базовые классы, миксины, работу с итераторами и автоматическое тестирование с помощью `pytest`.

## Возможности

* загрузка данных о категориях и товарах из JSON-файла;
* создание объектов `Category` и `Product`;
* хранение товаров внутри категорий;
* добавление товаров в категорию;
* проверка типа добавляемого товара;
* создание специализированных товаров `Smartphone` и `LawnGrass`;
* строковое представление товаров и категорий;
* подсчёт общего количества товаров на складе;
* сложение товаров одного класса;
* защита от сложения товаров разных классов;
* создание нового товара с помощью `classmethod`;
* изменение цены товара через `property`;
* создание абстрактного базового класса для товаров;
* создание заказа, содержащего один товар;
* расчёт итоговой стоимости заказа;
* выделение общей функциональности категорий и заказов в абстрактный класс;
* использование миксина для вывода информации о создании объекта;
* перебор товаров категории с помощью собственного итератора;
* обработка ошибок при загрузке JSON;
* автоматическое тестирование функциональности с помощью `pytest`.

## Формат данных

Исходные данные находятся в файле `data/products.json`.

Пример структуры:

```json
[
  {
    "name": "Смартфоны",
    "description": "Смартфоны, как средство не только коммуникации, но и получение дополнительных функций для удобства жизни",
    "products": [
      {
        "name": "Samsung Galaxy C23 Ultra",
        "description": "256GB, Серый цвет, 200MP камера",
        "price": 180000.0,
        "quantity": 5
      },
      {
        "name": "Iphone 15",
        "description": "512GB, Gray space",
        "price": 210000.0,
        "quantity": 8
      }
    ]
  }
]
```

Каждая категория содержит:

* `name` — название категории;
* `description` — описание категории;
* `products` — список товаров.

Каждый товар содержит:

* `name` — название товара;
* `description` — описание товара;
* `price` — цена;
* `quantity` — количество товара.

## Абстрактный класс BaseProduct

`BaseProduct` — абстрактный базовый класс для всех товаров.

Он содержит общие свойства:

* название товара;
* описание;
* цену;
* количество товара.

Для создания абстрактного класса используется модуль `abc`:

```python
from abc import ABC, abstractmethod
```

Методы `__str__` и `__add__` объявлены абстрактными и должны быть реализованы в дочерних классах.

Класс `BaseProduct` нельзя создать напрямую.

## Класс Product

`Product` является основным классом товара и наследуется от `BaseProduct`.

Класс содержит:

* название товара;
* описание;
* цену;
* количество товара.

### Строковое представление

Для товара реализован метод `__str__`:

```text
Samsung Galaxy C23 Ultra, 180000.0 руб. Остаток: 5 шт.
```

### Сложение товаров

Метод `__add__` позволяет получить общую стоимость двух товаров:

```python
product_1 + product_2
```

При расчёте учитывается количество каждого товара:

```text
цена × количество
```

Складывать можно только товары одинакового класса.

Например:

```python
smartphone_1 + smartphone_2
```

разрешено.

А попытка:

```python
smartphone + lawn_grass
```

приведёт к ошибке:

```text
TypeError
```

Проверка типа выполняется с помощью функции `type()`.

### Создание нового товара

Для создания нового товара используется класс-метод `new_product()`.

Если товар с таким названием уже существует, его количество увеличивается, а цена устанавливается как максимальная из старой и новой цены.

## Класс Smartphone

`Smartphone` является наследником `Product`.

Дополнительно содержит:

* эффективность;
* модель;
* объём памяти;
* цвет.

Пример:

```python
smartphone = Smartphone(
    "iPhone 15",
    "Смартфон Apple",
    100000,
    2,
    "Высокая",
    "15 Pro",
    "256 GB",
    "Black"
)
```

## Класс LawnGrass

`LawnGrass` является наследником `Product`.

Дополнительно содержит:

* страну производства;
* срок прорастания;
* цвет.

Пример:

```python
lawn_grass = LawnGrass(
    "Газонная трава",
    "Трава для газона",
    500,
    10,
    "Россия",
    "7 дней",
    "Зеленый"
)
```

## Класс Category

`Category` предназначен для хранения товаров одной категории.

Класс содержит:

* название категории;
* описание;
* список товаров.

### Добавление товара

Для добавления товара используется метод:

```python
category.add_product(product)
```

Перед добавлением выполняется проверка типа с помощью `isinstance()`.

В категорию можно добавить:

* объект `Product`;
* объект `Smartphone`;
* объект `LawnGrass`;
* любой другой класс, являющийся наследником `Product`.

Посторонние объекты добавить нельзя.

### Количество товаров

Строковое представление категории показывает общее количество единиц товара на складе:

```text
Смартфоны, количество продуктов: 13 шт.
```

Количество рассчитывается как сумма `quantity` всех товаров категории.

## CategoryIterator

`CategoryIterator` позволяет последовательно перебирать товары определённой категории.

Пример:

```python
iterator = CategoryIterator(category)

for product in iterator:
    print(product)
```

Итератор реализует методы:

* `__iter__`;
* `__next__`.

После окончания списка товаров вызывается `StopIteration`.

## BaseOrderCategory

`BaseOrderCategory` — абстрактный базовый класс, предназначенный для выделения общей функциональности категорий и заказов.

Использование абстрактного класса позволяет вынести общие свойства в одно место и использовать их в классах-наследниках.

Класс построен с использованием:

```python
from abc import ABC, abstractmethod
```

## OrderProduct

`OrderProduct` представляет собой заказ одного товара.

В заказе хранится:

* ссылка на товар;
* количество купленного товара;
* название заказа;
* итоговая стоимость.

Пример создания заказа:

```python
order = OrderProduct(
    product,
    2,
    "Заказ товара"
)
```

Итоговая стоимость рассчитывается по формуле:

```text
цена товара × количество
```

Например, если товар стоит `1000` рублей и заказано `2` единицы:

```text
Итоговая стоимость: 2000 рублей
```

В одном объекте `OrderProduct` может находиться только один товар.

## PrintInfoMixin

`PrintInfoMixin` используется для автоматического вывода информации о создании объекта.

Миксин реализован с использованием множественного наследования и `super()`.

При создании объекта:

```python
product = Product(
    "Продукт1",
    "Описание продукта",
    1200,
    10
)
```

в консоль выводится:

```text
Product('Продукт1', 'Описание продукта', 1200, 10)
```

Для определения фактического класса объекта используется:

```python
self.__class__.__name__
```

Миксин также работает с наследниками `Product`, например `Smartphone` и `LawnGrass`.

Пример:

```text
Smartphone('iPhone 15', 'Смартфон Apple', 100000, 2)
```

## Загрузка данных

Для загрузки данных используется функция `load_data_from_json()`:

```python
from src.utils import load_data_from_json

categories = load_data_from_json()
```

По умолчанию функция читает файл:

```text
./data/products.json
```

При необходимости можно передать собственный путь:

```python
categories = load_data_from_json("data/products.json")
```

Функция возвращает список объектов `Category`.

## Обработка ошибок

Функция загрузки данных обрабатывает следующие ситуации.

### Файл не найден

Если указанный JSON-файл отсутствует, функция возвращает пустой список:

```python
[]
```

### Некорректный JSON

При некорректном формате JSON обрабатывается исключение `JSONDecodeError`, после чего возвращается пустой список.

### Отсутствуют обязательные поля

Если в данных категории отсутствует одно из обязательных полей:

* `name`;
* `description`;
* `products`;

обрабатывается ошибка `KeyError`.
